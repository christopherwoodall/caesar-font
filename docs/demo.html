🛠️ Try it yourself

Curl Command

curl -s https://christopherwoodall.github.io/caesar-font/index.html | grep -A 20 '<p class="cipher">'

The output will look exactly like the encrypted text above. The browser on the live page uses a custom font to map those scrambled letters back into readable glyphs.

📖 Explanation

Why This Works

Web fonts are powerful. A font file contains a table that maps Unicode characters to glyph outlines. By editing that table, we can say: "when the browser sees the letter A, draw the shape of H instead." We do this for every letter, shifting by a fixed amount.

The HTML contains the shifted text. The font contains the reverse shift. Together they cancel out, revealing the hidden message. The source remains encrypted for anyone who does not have the font file.
