Curl Command

The demo page is a fully encrypted HTML document. View its source or run this command to see what the server actually sends:

curl -s https://christopherwoodall.github.io/caesar-font/demo.html | grep -A 20 '<p class="cipher">'

The output is pure ciphertext. The browser uses the custom font to map each scrambled letter back to its original glyph. The font is the decryption key.

📐 The Maths

How the Shift Works

The Caesar cipher is one of the oldest encryption techniques. Each letter in the alphabet is replaced by a letter a fixed number of positions away.

E(x) = (x + 7) mod 26

Where x is the position of a letter in the alphabet (A=0, B=1, ..., Z=25), and n is your chosen shift. The mod 26 wraps around at the end of the alphabet.

The custom font applies the inverse shift. When the browser sees an encrypted letter, it draws the glyph of the original letter instead.

ℹ️ How It Works

The Mechanism

Web fonts are powerful. A font file contains a table that maps Unicode characters to glyph outlines. By editing that table, we can say: "when the browser sees the letter A, draw the shape of H instead." We do this for every letter, shifting by a fixed amount.

The HTML contains the shifted text. The font contains the reverse shift. Together they cancel out, revealing the hidden message. The source remains encrypted for anyone who does not have the font file.

This is a playful demonstration of how presentation and content can be separated. What you see is not always what you get.
